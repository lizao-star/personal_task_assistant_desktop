# 飞书表结构：个人任务助理

> 飞书多维表格「个人任务助理」的完整表结构与自动化配置说明。
> 本文档描述**当前已建成的表**；后续各阶段需补充的字段见 [设计总纲.md](设计总纲.md) 第 4.2 节。
> 返回入口：[CLAUDE.md](../CLAUDE.md)

多维表格共 **6 张表**，核心是**任务表**，其余为辅助：

任务表 / 子任务表 / 目标项目表 / 每日复盘表 / 娱乐监控日志表 / 设置表

**三层任务体系**（AI 建任务按此判层级，见 [设计总纲.md](设计总纲.md) 4.0）：

| 层级         | 表         | 时间尺度 | 判断标准                       | 例子                     |
| ------------ | ---------- | -------- | ------------------------------ | ------------------------ |
| L1 目标/项目 | 目标项目表 | ≥30 天   | 且**需持续投入、可分阶段推进** | 研一结束前完成小论文初稿 |
| L2 任务      | 任务表     | 1~30 天  | 可安排进日程                   | 写完文献综述第二章       |
| L3 子任务    | 子任务表   | 1 天内   | 一次坐下能完成                 | 精读 3 篇核心文献        |

关联链：任务表「所属目标」→ 目标项目表；子任务表「所属任务」→ 任务表。

> 远期但一次性办完的事（会议/体检/报到/面试/领取材料）即使超过 30 天也放任务表，不放目标表。

---

## 一、任务表（主表）

1~30 天、可安排进日程的任务都放这里；30 天以上且需持续投入的大方向建到目标项目表，一天内能完成的动作建为子任务。

| ------------ | -------- | ---------------------------------------------------- | ---- | ------------------------------------------------------- |
| 任务ID       | 自动编号 | 自动                                                 | 是   | 系统生成                                                |
| 任务名       | 文本     | 一句话                                               | 是   | 例如「写课程论文引言」                                  |
| 描述         | 多行文本 |                                                      | 否   | 详细说明                                                |
| 状态         | 单选     | 收集箱、待办、进行中、等待、已完成、已取消、延期     | 是   | 默认「收集箱」                                          |
| 优先级       | 单选     | P0、P1、P2、P3                                       | 是   | P0 最紧急                                               |
| 任务类型     | 单选     | 课程、科研、作业、考试、组会、生活、其他             | 是   | 用于分类                                                |
| 来源         | 单选     | 微信、课程网站、老师、自己、飞书、邮件、其他         | 否   | 任务从哪来                                              |
| 所属目标     | 关联     | 关联「目标/项目表」                                  | 否   | 一个任务可属于一个目标                                  |
| 标签         | 多选     | 论文、编程、阅读、实验、汇报、英语等                 | 否   | 自定义                                                  |
| 截止时间     | 日期时间 | 年/月/日 时:分                                       | 是   | 最关键字段                                              |
| 开始时间     | 日期时间 | 年/月/日 时:分                                       | 否   | 计划开始时间                                            |

| 子任务       | 关联     | 关联「子任务表」                                     | 否   | 一对多                                                  |

| 优先级分数   | 公式     | 数字                                                 | 否   | 用于自动排序                                            |
| 精力需求     | 单选     | 高、中、低                                           | 否   | 匹配当天状态                                            |
| 场景         | 单选     | 电脑、手机、图书馆、实验室、教室、宿舍               | 否   | 在哪儿做                                                |

### 视图

收集箱 / 今日待办 / 本周待办 / 逾期任务 / P0-P1 / 进行中 / 已完成 / 按截止时间升序 / 按优先级分数降序。

## 三、目标/项目表

跨月、长期（≥30 天且需持续投入）的目标/项目（AI 建任务判定 `level=goal` 时写入本表，并自动向下拆解为任务表记录，见 [设计总纲.md](设计总纲.md) 4.0 与 5.4）。同一时间活跃目标建议 ≤ 5 个。

> 判定为目标的**必要条件**：距截止 ≥30 天 **且** 需要持续投入、可分阶段推进。
> 远期但一次性办完的事项（开会、体检、报到、面试、领材料）不写入本表，仍进任务表。

管理年、季、月、周目标。

| 字段名   | 类型      | 选项 / 格式                        | 必填 | 说明                                                      |
| -------- | --------- | ---------------------------------- | ---- | --------------------------------------------------------- |
| 目标ID   | 自动编号  | 自动                               | 是   | 系统                                                      |
| 目标名   | 文本      |                                    | 是   | 例如「研一结束前完成小论文初稿」                          |
| 层级     | 单选      | 年、季、月、周                     | 是   |                                                           |
| 开始时间 | 日期      |                                    | 否   |                                                           |
| 结束时间 | 日期      |                                    | 否   |                                                           |
| 状态     | 单选      | 未开始、进行中、已完成、暂停、取消 | 是   |                                                           |
| 描述     | 多行文本  |                                    | 否   |                                                           |
| 关键结果 | 多行文本  | 每行一个                           | 否   | OKR 思路                                                  |
| 关联任务 | 关联      | 关联「任务表」                     | 否   | 反向关联                                                  |
| 进度     | 公式/进度 |                                    | 否   | 完成任务数/总任务数                                       |
| 复盘     | 多行文本  |                                    | 否   | 阶段结束写                                                |
| 外部ID   | 文本      |                                    | 否   | **M4.5 新增（客户端必需）**：幂等键，格式 `win-<12位hex>` |
| 同步来源 | 单选      | 手动、客户端、机器人、服务器、AI   | 否   | **M4.5 新增**：标识记录由哪一端写入                       |
| 修改时间 | 日期      |                                    | 否   | **M4.5 新增**：增量同步游标依据（客户端只读远端值）       |

> 但目标级写入无法幂等重试、增量同步退化为全量拉取。

## 六、设置表

存运行配置，**不要存 API Key 明文**。

| 字段名 | 类型     | 选项 / 格式 | 必填 | 说明             |
| ------ | -------- | ----------- | ---- | ---------------- |
| 配置项 | 文本     |             | 是   | 例如「勿扰开始」 |
| 值     | 文本     |             | 是   | 例如「23:00」    |
| 说明   | 多行文本 |             | 否   |                  |

**建议配置项**

| 配置项           | 示例值                         |
| ---------------- | ------------------------------ |
| 勿扰开始 / 结束  | 23:00 / 07:00                  |
| 默认提醒         | 提前1天、提前2小时、提前10分钟 |
| 娱乐网站阈值     | 30 分钟                        |
| 抖音进程名       | douyin.exe                     |
| 是否语音提醒     | 是                             |
| 每日复盘时间     | 22:00                          |
| 今日任务推送时间 | 08:00                          |

> **安全红线**：`API Key` / `App Secret` 不要放这里，只放 Windows 环境变量或本地 `config/.env`，且不上传。

## 七、创建顺序

1. 新建多维表格，命名「个人任务助理」。
2. 先建「任务表」，按上面字段加。
3. 建「子任务表」，用「所属任务」关联任务表。
4. 建「目标/项目表」，用「关联任务」关联任务表。
5. 建「每日复盘表」。
6. 建「娱乐监控日志表」。
7. 建「设置表」。
8. 在任务表建视图：收集箱、今日待办、本周待办、逾期、P0/P1。
9. 配自动化（见下节）。

## 八、飞书自动化配置

### 1. 截止时间提醒（到达记录中的时间时）

最关键，建议配「提前 1 天」和「提前 2 小时」两条。

- 触发：`到达记录中的时间时`，表选「任务表」，时间字段选「截止时间」，设置提前 1 天 / 2 小时。
- 执行：`发送飞书消息`，接收人选「第 1 步触发的记录」>「创建人」。
- 消息示例：`⚠️ 任务「[任务名]」将在 1 天内截止，请及时处理。`
- 保存并启用。

### 2. 每日任务推送与晚间复盘（定时触发）

- 触发：`定时触发` → 每天 → 08:00。
- 执行：`发送飞书消息`，接收人选自己，内容用「+ 插入 → 查找记录」，筛选「截止时间 = 今天」且「状态 ≠ 已完成」。
- 晚间复盘：复制流程，时间改 22:00，筛选改为「状态 = 待办」或「进行中」。

### 3. 重要任务监督（记录满足条件时）

- 触发：`新增/修改的记录满足条件时`。
- 条件：「优先级 = P0」且「状态 = 进行中」。
- 执行：发送飞书消息提醒自己。

### 管理与测试

右上角「自动化 → 管理」可查看全部流程并启停。务必用测试数据新增一条记录，确认能正常收到飞书消息。

## 九、公式字段

飞书公式语法与 Excel 不完全一样，**先不加**「优先级分数」「完成率」等公式，等基础跑通后（M7）再按实际字段名生成。

优先级排序先用简单规则：

1. 逾期任务最优先
2. P0 最优先
3. 截止时间近的优先
4. 预计耗时短的先做
5. 依赖别人的任务先推进

> 客户端已用 [priority.py](../client_windows/app/services/priority.py) 实现加权公式版本，不依赖飞书公式字段。
