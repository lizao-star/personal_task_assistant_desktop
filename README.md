# 个人学习任务助理

面向研究生的「**飞书多维表格为中心 + AI 规划 + 桌面监督**」个人效率系统。

> 一句话定位：**AI 帮我规划、拆解、提醒、监督、复盘**——不是「AI 帮我完成任务」。

当前进度：**M4.5 三层任务打通已完成**（目标/项目 → 任务 → 子任务；AI 判层级 + 目标级拆解）；上一阶段 M4（娱乐监督 L4 + 番茄钟）已完成。

## 功能现状

- [x] 读取飞书多维表格「任务表」，自动分页拉取
- [x] 展示**待办任务**（全部未结束且未逾期，含无截止时间）、**逾期任务**与**收集箱**三个互斥视图，按优先级分数排序
- [x] 待办列表默认折叠，只显示前 5 个最重要的任务，其余可通过「展开全部」按钮查看
- [x] 本地 SQLite 缓存，断网时仍可显示最近一次任务
- [x] Windows 系统通知 + 离线中文语音（仅勾选「是否语音提醒」的任务）
- [x] 勿扰时段（默认 23:00–07:00）静默；提醒暂停开关
- [x] 系统托盘常驻、关闭窗口最小化到托盘、开机自启（自启命令固定用项目 venv 的 pythonw.exe；已注册 AppUserModelID，任务栏显示应用自己的 logo 而非宿主解释器图标）
- [x] **客户端写回**：新建任务 / 完成 / 延期（M2）
- [x] **离线队列**：断网时操作入队，恢复后自动补交，幂等不重复（M2）
- [x] **增量同步**：按「修改时间」游标只拉变化的部分（M2）
- [x] **冲突提示**：推送前发现云端已更新会弹窗询问是否覆盖（M2）
- [x] **目标计划区（M4.5）**：主窗口顶部列出「目标/项目表」全部目标，展示层级/状态/进度/起止时间/关联任务数；鼠标悬停显示关键结果，双击打开可编辑目标详情；进度由飞书「进度」公式列自动计算，客户端只读展示
- [x] **三层任务打通（M4.5）**：L1 目标/项目（距截止 ≥30 天且需持续投入）→ L2 任务（1~30 天）→ L3 子任务（1 天内）；任务表通过「所属目标」关联目标，子任务表通过「所属任务」关联任务
- [x] **AI 自动判层级 + 目标拆解（M4.5）**：新建时 AI 判定层级，并由规则引擎复核——**远期但一次性办完的事（开会/体检/报到）仍判任务，不会误升为目标**；判低的疑似目标会追加一次按目标拆解的追问；**目标是必须向下拆解的**（拆不出 ≥2 个 L2 任务则降级为普通任务并进收集箱待确认）；普通任务仅在确实需要时才拆子任务，宁缺勿碎
- [x] **拆解质量（M4.5）**：拆解区分「策略建议（怎么做好）/ 执行步骤 / 一次性核对项」；策略建议写入「AI建议」列；报名截止、打印准考证这类中间节点直接落成带截止时间的任务（任务级则作为一条子任务），不另设概念
- [x] **任务依赖（M4.5）**：目标拆解时 AI 顺带输出任务间依赖（先报名 → 才能打印准考证），落表回填任务表「依赖任务」关联列；待办区排序在优先级分数基础上尊重依赖，前置任务始终排在依赖它的任务之前，不再出现「下级任务排在上级任务前」的倒挂
- [x] **任务详情（M3，M4.5 合并编辑）**：点「详情」或**双击任务行**打开可编辑详情页，展示并可直接修改 14 项字段（含所属目标）、AI拆解/AI建议/检查清单/子任务进度，页内还能「AI 拆解此任务」并采纳（子任务需在 `.env` 配置 `FEISHU_SUBTASK_TABLE_ID`）
- [x] **AI 一句话建任务**：输入自然语言，DeepSeek 解析为结构化任务（含截止时间/优先级/子任务/检查清单），确认后入库（M3；需配置 `DEEPSEEK_API_KEY`）
- [x] **AI 拆解已有任务**：详情页点「AI 拆解此任务」，预览建议后一键采纳或忽略（M3）
- [x] **置信度兜底**：AI 解析置信度低于阈值自动写入「收集箱」待确认；断网/Key 错误退化为只取标题，程序不崩（M3）
- [ ] 手机端 AI 拆解（豆包 agent 方案，见 [docs/豆包agent轻量化方案.md](docs/豆包agent轻量化方案.md)，纯手动配置无需代码）
- [x] **娱乐监督（M4）**：5 秒采样前台窗口 + 浏览器扩展上报；**黑名单命中（娱乐域名/标题/进程）才计时**，白名单豁免；L1 通知 → L2 语音 → L3 提醒 → L4 动作（全屏遮挡 / 强制关闭网页二选一）；会话结束聚合写飞书「娱乐监控日志表」
- [x] **本地 API（M4）**：`127.0.0.1:8765` 接收扩展上报与下发关标签请求；不暴露公网
- [x] **浏览器扩展（M4，MV3）**：5 秒上报域名/标题（仅当前聚焦标签）；关标签经 background service worker 执行 `chrome.tabs.remove`
- [x] **番茄钟（M4 补充）**：托盘菜单开始/停止，25 分钟专注 + 5 分钟休息自动轮转，阶段结束系统通知 + 语音；纯计时不绑定任务、不与娱乐监督联动，时长可在 `settings.yaml` 配置
- [ ] 飞书机器人（M5，可用豆包 agent 替代）

## 快速开始

### 1. 准备飞书应用（一次性）

1. 打开[飞书开放平台](https://open.feishu.cn/)，创建**企业自建应用**，记录 `App ID` 与 `App Secret`。
2. 在「权限管理」开通多维表格**读写**权限：`bitable:app`（M2 起必须，仅只读会导致写回失败）。
3. 创建应用版本并发布；然后打开你的多维表格，点右上角「... → 添加文档应用」，把该应用加为协作者。
4. 从多维表格 URL 取得：
   - `app_token`：URL 中 `/base/` 后面那段；
   - `table_id`：打开任务表后 URL 中 `table=` 参数。
5. **手动给任务表新增 2 个字段**（M2 需要，飞书 OpenAPI 不允许客户端建字段）：
   - `外部ID`（**文本**）—— 客户端写入的幂等键，防断网重试造成重复记录
   - `同步来源`（**单选**，选项：手动 / 客户端 / 机器人 / 服务器 / AI）
6. **目标/项目表（M4.5 可选）** 同样需新增 `外部ID`（文本）、`同步来源`（单选）两个字段，
   并把表 ID 写入 `.env` 的 `FEISHU_GOAL_TABLE_ID`，客户端才能拉取目标并在新建时写入目标。
7. **时间列必须是系统字段**：任务表与目标表的 `修改时间` 都要建成系统「修改时间」（自动更新），
   任务表还建议保留系统「创建时间」。普通日期列不能被 `records/search` 过滤，
   会报 `code=1254018 InvalidFilter`；客户端也已开启 `automatic_fields`，
   字段缺失时回退用记录级 `last_modified_time` 兜底。

### 2. 创建并激活虚拟环境

```powershell
cd client_windows
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. 安装依赖

```powershell
pip install -r requirements.txt
```

### 4. 配置凭证

```powershell
# 回到工作区根目录操作
copy config\.env.example config\.env
```

编辑 `config/.env`，填入四个必填项：`FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_APP_TOKEN`、`FEISHU_TASK_TABLE_ID`。
另外把 `FEISHU_SUBTASK_TABLE_ID` 取消注释并填上子任务表的 `table=` 参数，客户端详情里才能看到拆出的子任务（不填则详情只显示文本字段）。

如需新建任务里的 AI 解析 / 详情页 AI 拆解（M3），再到 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请 API Key 并填入 `DEEPSEEK_API_KEY`；不填则 AI 解析按钮置灰（纯手动新建不受影响），其余功能不受影响。

如需娱乐监督聚合日志入库（M4），把 `FEISHU_MONITOR_LOG_TABLE_ID` 取消注释并填上飞书「娱乐监控日志表」的 `table=` 参数；不填则监督仍可运行（仅本地缓存，不入飞书）。

如需三层任务打通（M4.5），把 `FEISHU_GOAL_TABLE_ID` 取消注释并填上飞书「目标/项目表」的 `table=` 参数；不填时主窗口不显示目标计划区，客户端仍可正常管理 L2 任务。

### 5. 验证连接（可选，不开界面）

```powershell
cd client_windows
python test_connection.py
```

### 6. 运行

```powershell
cd client_windows
python run.py
```

启动后托盘出现图标；双击图标或菜单「打开主界面」查看今日待办。

## 常用操作

| 操作          | 方式                                                                                                                                |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 立即同步      | 主窗口按钮或托盘菜单（触发**全量**同步）                                                                                            |
| 新建任务      | 主窗口「新建任务」按钮：直接填表单，**或在顶部一句话输入后点「AI 解析填充」自动填表**（可再手改）；低置信度自动进收集箱             |
| 查看/编辑任务 | **双击任务行**（或选中后点「详情」）→ 打开可编辑详情页，改字段后「保存」立即生效并同步飞书（14 项字段，含所属目标/AI拆解/检查清单） |
| 表单看不全    | 新建任务 / 任务详情对话框的**内容区可纵向滚动**，底部按钮固定；窗口初始尺寸按屏幕可用区域自动收缩，小屏幕不会超出边界               |
| 查看目标      | 主窗口顶部「🎯 目标计划」区，双击目标行查看层级/进度/起止/关键结果                                                                   |
| 编辑目标      | **双击目标行**打开可编辑目标详情页（目标名/层级/状态/起止/描述/关键结果），保存后经离线队列同步飞书，冲突时弹窗确认                 |
| 目标进度      | 由飞书「进度」公式列自动计算（已完成关联任务占比），客户端只读展示，不可也不必手动修改                                              |
| AI 拆解       | 详情页点「AI 拆解此任务」→ 预览子任务/清单/建议 → 采纳写入（对话框不关闭，可继续改）或忽略                                          |
| 完成任务      | 选中行 → 点「完成」；状态与完成时间立即写入飞书                                                                                     |
| 延期任务      | 选中行 → 点「延期」，可选今晚 23:59 / 明天 18:00 / 自定义时间                                                                       |
| 暂停/恢复提醒 | 主窗口按钮或托盘菜单（同时暂停娱乐监督，受 `pause_with_reminder` 控制）                                                             |
| 娱乐监督开关  | 托盘菜单「娱乐监督」勾选                                                                                                            |
| 关闭程序      | 托盘菜单「退出」（点窗口 × 只是隐藏到托盘）                                                                                         |

> 「完成 / 延期 / 详情」作用于**最后点击的那张表格**中选中的行：点击某张表会自动清除
> 其他表的选中，避免待办/逾期/收集箱之间的残留选中导致操作错行。

### 离线队列与冲突

- 断网时新建/完成/延期/**编辑**会**先入本地队列**（状态栏显示「待推送 N 条」），恢复网络后自动按序补交。
- 每条新建任务带唯一的 `外部ID`，重试时按 `外部ID` 查重，**不会重复建单**。
- 推送前若发现云端「修改时间」比本地新（手机端已改过），会弹窗询问是否覆盖：选「是」用本地覆盖云端，选「否」放弃本次操作并以云端为准。

## 运行配置

`config/settings.yaml`（无需密钥，可提交）：

- `sync.interval_seconds`：自动同步间隔，默认 45 秒
- `do_not_disturb`：勿扰时段，默认 23:00–07:00
- `reminder.check_interval_seconds`：提醒检查间隔，默认 30 秒
- `reminder.missed_window_minutes`：错过提醒的补发窗口，默认 60 分钟
- `reminder.tts.engine`：语音引擎，当前支持 `pyttsx3`
- `ai.confidence_threshold`：AI 解析置信度阈值，低于该值写入收集箱待确认，默认 0.6
- `ai.timeout_seconds`：单次 AI 请求超时，默认 60 秒
- `monitor.enabled`：娱乐监督总开关，默认 `true`
- `monitor.sample_interval_seconds`：监督采样间隔，默认 5 秒
- `monitor.grace_seconds`：容忍窗口（秒），默认 60；窗口内短暂切走不结束会话、切回不重复写日志；0 表示关闭容忍（切走即结束）。所有娱乐平台共用同一会话与计时器，切换平台不清零
- `monitor.whitelist_titles` / `whitelist_domains`：白名单关键词，命中即不计时（优先于黑名单）
- `monitor.blacklist_domains` / `blacklist_keywords` / `blacklist_processes`：娱乐黑名单，**必须命中才计时**；三者全空则监督不生效
- `monitor.escalation.l1_minutes`~`l4_minutes`：四级升级阈值，默认 10/20/30/45 分钟
- `monitor.l4_action`：L4 触发的动作，`overlay`（全屏遮罩）或 `kill_tab`（强制关闭网页）
- `monitor.pause_with_reminder`：暂停提醒时是否同时暂停监督，默认 `true`
- `monitor.local_api_port`：本地 API 端口，默认 8765（仅供浏览器扩展上报）
- `pomodoro.focus_minutes` / `rest_minutes`：番茄钟专注/休息时长，默认 25/5 分钟

## 资源占用目标

- 常驻内存 < 150 MB，空闲 CPU < 1%
- 自动同步默认 45 秒一次（飞书 API 有限流，不建议更短）

## 浏览器扩展安装（M4 监督，可选）

1. 打开 Edge 或 Chrome，访问 `edge://extensions` / `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点「加载解压缩的扩展」，选择 `client_windows/extension` 目录。
4. 扩展会自动连本地客户端（`http://127.0.0.1:8765/health`）；不装也能用监督，但只能基于前台窗口标题判断，不能精确关单个标签页（会降级为关整个浏览器窗口）。
