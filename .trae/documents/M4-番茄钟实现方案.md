# 番茄钟（Pomodoro）实现方案

## Context

M4 娱乐监督已完成，番茄钟当时推后（见 `docs/路线图.md` M4 节备注）。现在补上，**用户已确认最小范围**：

- **纯计时，不绑定任务**，不写回飞书「实际耗时」
- **与娱乐监督完全不联动**（不豁免、不暂停监督）
- **入口仅托盘菜单**
- **默认 25/5，settings.yaml 可配置**

设计总纲中「番茄钟绑定任务累计实际耗时」「休息期豁免监督」为后续扩展项，本期不做。

## 功能行为

托盘菜单新增「番茄钟」组：

- **开始番茄钟**：启动 25 分钟专注计时，菜单项变为「停止番茄钟（剩 MM:SS）」；专注结束 → 系统通知 + TTS「专注结束，休息 5 分钟」→ 自动进入 5 分钟休息计时；休息结束 → 通知 + TTS「休息结束」→ 回到空闲态。
- **停止番茄钟**：任何时候可手动停止，回到空闲态，不提示。
- 状态机：`idle → focus → rest → idle`，内存态即可，**不落 SQLite、不写飞书**（重启即丢，符合最小范围）。
- 提醒遵守现有 `do_not_disturb` 勿扰时段（复用 `Notifier` 内部已有逻辑，不额外处理）。

## 改动清单

### 1. 新建 `client_windows/app/services/pomodoro.py`（纯逻辑 + Worker）

模仿 `monitor.py` 的模式，但更简单——不需要独立 QThread，直接用主线程 `QTimer`（每秒 tick 更新菜单文案，无 IO、无阻塞）：

```python
class PomodoroTimer(QObject):
    """番茄钟：idle → focus → rest → idle，纯计时，不与监督联动。"""
    state_changed = Signal(str, int)   # (state, remaining_seconds)；state ∈ idle/focus/rest
    phase_finished = Signal(str, str)  # (finished_phase, 提示文案)
```

- `start()` / `stop()` / `state` / `remaining`
- 内部 `QTimer(1000ms)`，tick 时减秒、归零切换阶段并发 `phase_finished`
- 时长从构造参数注入（`focus_seconds` / `rest_seconds`），便于测试
- 纯状态转移逻辑抽成模块级纯函数 `next_phase(state) -> str`，配单测

### 2. `client_windows/app/ui/tray.py`

在「娱乐监督」之后插入：

- `self.pomodoro_action = QAction("开始番茄钟", parent)`（不可 check，点击即开始/停止）
- 新增 `set_pomodoro_state(state: str, remaining: int)` 方法更新文案：
  - idle → `"开始番茄钟"`
  - focus → `"停止番茄钟（专注剩 24:35）"`
  - rest → `"停止番茄钟（休息剩 04:12）"`

### 3. `client_windows/app/main.py` 接线（模仿 L193-L198 托盘接线段）

- `__init__` 或 `_setup` 中创建 `self._pomodoro = PomodoroTimer(focus_seconds, rest_seconds)`，时长读 `settings["pomodoro"]`
- `self.tray.pomodoro_action.triggered.connect(self._on_pomodoro_clicked)`：idle 则 start，否则 stop
- `state_changed` → `self.tray.set_pomodoro_state(...)`
- `phase_finished` → `self._notifier.notify("番茄钟", text)` + `self._notifier.speak(text)`（复用 L539-L541 的通知模式）
- `shutdown()` 中 `self._pomodoro.stop()`

### 4. `config/settings.yaml`

```yaml
# 番茄钟设置（M4 补充；纯计时，不绑定任务、不与娱乐监督联动）
pomodoro:
  focus_minutes: 25   # 专注时长
  rest_minutes: 5     # 休息时长
```

### 5. 单测 `client_windows/tests/test_pomodoro.py`

- `next_phase` 纯函数：idle→focus→rest→idle 状态转移
- `PomodoroTimer` 用 1 秒/2 秒注入时长 + `QSignalSpy` 或手动驱动 tick：开始、阶段切换、停止、剩余秒数计算（不依赖真实 25 分钟等待）

## 不做的事（明确排除）

- 不绑定任务、不写「实际耗时」、不入 SQLite、不写飞书
- 不与娱乐监督联动（监督照常运行）
- 不做长休息（每 4 个番茄）——后续需要再加
- 主窗口不加番茄钟 UI（仅托盘）
